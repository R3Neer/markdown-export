# Changelog

All notable changes to R3 Markdown Export are documented here.

## 0.1.0 — 2026-09-03

- Extract the portable Markdown exporter from Mud as an independent package.
- Add the `markdown-export` command and R3CLI help and diagnostics.
- Add a desktop Obsidian adapter that uses the installed command.
- Support combined documents, size-based parts and path-preserving ZIP files.
- Preserve profiles, link discovery, source markers and the local web interface.
